# Sessions

A **session** groups the turns of one conversation with one face. **Compacting** a session
returns a summary of the face's position over the session, in the face's own terms, stored
under a `compaction_id`. Send that id on a later request with the same face, and its cause
reads the summary in place of the history you no longer send.

A session belongs to the account that opened it and to its face. Another account, or another
face, cannot use it.

## Start a session

`model` is the face alone (`alice`, `owner:alias`) or a
[composite](/guides/synthetic-faces#run-time-composites-compose-on-the-fly), not `face@model`.

```bash
curl -X POST https://api.faces.sh/v1/sessions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model": "alice"}'
```

```json
{"object": "session", "id": "fs_SESSION_ID", "model": "alice", "turns": 0, "status": "open",
 "created_at": "2026-10-22T09:00:00+00:00", "last_used_at": "2026-10-22T09:00:00+00:00",
 "expires_at": "2026-11-21T09:00:00+00:00"}
```

## Attach turns

Add `"session": "<id>"` to any request with that face: [causes](/guides/causes),
[chat](/guides/chat) (`/v1/chat/completions`, `/v1/responses`, `/v1/messages`) and
[decisions](/guides/decisions) (`/v1/decisions`, `/v1/systemone`). The face may be addressed
alone or as `face@MODEL`. Each turn is billed as it would be without a session.

```json
{"model": "alice@MODEL", "session": "fs_SESSION_ID",
 "messages": [{"role": "user", "content": "Should I take the offer?"}]}
```

## Compact

```bash
curl -X POST https://api.faces.sh/v1/sessions/fs_SESSION_ID/compact \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```json
{"object": "cause.compaction", "compaction_id": "fcmp_COMPACTION_ID",
 "session_id": "fs_SESSION_ID", "cause": "…", "turns": 8,
 "created_at": "2026-10-22T09:40:00+00:00", "expires_at": "2026-11-21T09:40:00+00:00",
 "usage": {"input_tokens": 5210, "output_tokens": 640}}
```

`cause` is the summary, in plain words. `turns` is the number of turns it covers. A session
can be compacted again as it grows; each compaction has its own id.

A compaction is held open like a cause: see [Speed](/guides/causes#speed).

## Use a compaction

Add `"compaction": "<compaction_id>"` to a later request with the same face, on any of the
routes above. Send only the messages you still want read; the face's cause reads the
summary alongside them.

```json
{"model": "alice@MODEL", "compaction": "fcmp_COMPACTION_ID",
 "messages": [{"role": "user", "content": "So what do I tell them tomorrow?"}]}
```

`compaction` and `session` can go together: the turn joins the session and reads the
compaction. A request with no face ignores both fields.

## Read a session

```bash
curl https://api.faces.sh/v1/sessions/fs_SESSION_ID \
  -H "Authorization: Bearer YOUR_API_KEY"
```

Returns the session object, as on creation, with `turns` and `last_used_at` up to date.

## Close a session

`DELETE /v1/sessions/{session_id}` closes it: `{"object": "session", "id": "fs_SESSION_ID",
"status": "closed"}`. A closed session takes no more turns and cannot be compacted or read.
Its compactions stay usable until they expire.

## Cost

- Opening, reading and closing a session are free. A turn costs what it costs without one.
- **Compacting** is billed at the [cause rate](/guides/billing#current-rates) (`cause` in
  [`GET /v1/rates`](/guides/billing#current-rates)) on the tokens it reads and writes,
  `usage.input_tokens + usage.output_tokens`. On Connect and Pro it counts against the cause
  [allowance](/guides/billing#allowances).
- **Using** a compaction adds its text to what the cause reads, and is billed with that cause.
- A compaction that fails is not charged.

Creating and compacting a session count against your plan's per-minute
[rate limit](/errors#rate-limits).

## Expiry

A session expires 30 days after its last turn: each turn moves `expires_at` forward. A
compaction expires 30 days after it is written. Both report `expires_at`. An expired session
or compaction answers as one that does not exist.

## Errors

`detail` is a string.

| Status | When | `detail` |
|--------|------|----------|
| `404` | The session does not exist, has expired or been closed, or is another account's (create, read, close, compact) | `no such session, or it has expired` |
| `404` | A turn sends a `session` that is unknown, expired, closed, another account's or another face's | `no such session, or it has expired. Nothing was charged.` |
| `404` | A turn sends a `compaction` that is unknown, expired, another account's or another face's | `no such compaction, or it has expired. Nothing was charged.` |
| `422` | `model` is missing on create | `` `model` is required: the face the session is with `` |
| `422` | `model` is `face@model` on create | `` a session is with a face alone: send `model: "alice"` `` |
| `422` | `session` or `compaction` is not a string, or longer than 64 characters | `` `session` must be an id string, as returned by /v1/sessions `` |
| `422` | Compacting a session with no turns | `the session has no turns to compact yet. Nothing was charged.` |
| `402` | Compacting with no credit left | See [Billing](/guides/billing). |
| `403` | The API key may not use the session's face | See [Errors](/errors). |
| `429` | The per-minute rate limit, or the cause allowance is used and `api_fallback` is off | Names the limit. |
| `503` | Compaction is unavailable, or failed | `compaction is not available right now; retry later. Nothing was charged.` or `the compaction failed; retry. Nothing was charged.` |
