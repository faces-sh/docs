# Chat (retired)

Chat is retired. `POST /v1/chat/completions`, `POST /v1/responses` and `POST /v1/messages`
answer `410 Gone` with the error code `chat_retired`, and nothing is charged:

```json
HTTP 410
{
  "detail": "Chat is retired. Use POST /v1/choices with model \"maestro-1\" and view \"@<alias>\" (and /v1/states for the situation). Nothing was charged.",
  "error": {"type": "gone", "code": "chat_retired", "message": "Chat is retired. Use POST /v1/choices with model \"maestro-1\" and view \"@<alias>\" (and /v1/states for the situation). Nothing was charged."}
}
```

`error` is the shape OpenAI- and Anthropic-compatible clients read.

To run a face, use [`POST /v1/choices`](/guides/choices): describe the situation, ask a
question, and the face proposes the options it would weigh. Keep a longer situation in a
[state](/guides/states). For typed answers, use [decisions](/guides/decisions); for the
face's cause alone, use [causes](/guides/causes).

[Fidelity runs](/guides/fidelity), which compared chat answers, are retired with it.
